# Basic VueJs+whisper+LLM showcase

## Input
- YouTube link of call center calls

## Features
- **Real-time transcription with speaker separation**
- **Streaming translation as the audio is processed**
- **LLM-generated summary and conclusion** (was the issue resolved?)
- **Sentiment analysis for each speaker**
- **Highlight key issues and suggest follow-up actions**

## Goal
Showcase advanced speech-to-text, NLP, and real-time streaming tech for better call center operations and customer service.
